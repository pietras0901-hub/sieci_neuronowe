# 🧠 Sieci Neuronowe - Projekty ML

Zbiór projektów z zakresu uczenia maszynowego i sieci neuronowych.

## Projekty

### 🍎 Jabłko vs Banan
Klasyfikator obrazów oparty na TensorFlow.js działający w przeglądarce.

### 🐶 Pies vs Kot  
Klasyfikacja obrazów psów i kotów w Pythonie.

### 🌸 Irys CNN
Sieć konwolucyjna (CNN) do klasyfikacji zbioru Iris.

### 📊 MLP Lab
Sieć MLP (Multilayer Perceptron) — ćwiczenia laboratoryjne.

## Technologie
- Python, TensorFlow, Keras
- Jupyter Notebook
- TensorFlow.js
